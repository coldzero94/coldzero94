I build systems end to end and keep them small.

Right now that's **[push-point](https://github.com/coldzero94/push-point)** — a self-hosted link archive that auto-tags what you save, without an LLM API. One Go binary on SQLite, a rule-based Korean tagger scored against a frozen golden set, FTS5 search that matches Korean without a morphological analyzer, and iOS, web and browser clients built from one OpenAPI contract. Save p99 is 0.98 ms against a 50 ms target, and a backup is a copy of `data/`.

By day I'm a Forward Deployed Engineer at VESSL AI, building agent platforms end to end — the agents, MCP servers and eval infra behind them — that ship in production vehicles and air-gapped government clouds.
